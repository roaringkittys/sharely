How Mobile Login Works

1. Bookmarklets are just saved bookmarks that run code.

  1. Pick an account below (e.g., Netflix — Prime 1)
  2. Copy the bookmarklet link, save it as a bookmark in Safari/Chrome
  3. Next time you visit that site, tap the saved bookmark
  4. It injects all session cookies instantly and refreshes the page

Why can't we just click it directly?
For security, browsers only allow bookmarklets to set cookies when run from a saved bookmark on the actual site. Copy + save once, use forever.

On iPhone/Safari:
Share sheet → Add Bookmark → paste the URL → save. Rename it to "Netflix 1" for easy access.

On Android/Chrome:
Tap and hold the link → Copy link → go to bookmarks → add → paste the URL.
